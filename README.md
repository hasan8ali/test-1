# test-1

Repository تجريبي للإختبار والتأكد من أن الـ workflow بيننا يعمل بشكل صحيح.

## مرحباً

أهلاً! هذا الـ repository تم إنشاؤه كتجربة للتأكد من أننا نقدر نشتغل مع بعض بطريقة منظمة:
- إنت تطلب ميزة/تعديل
- أنا أعمل التعديل وأعمل `commit` واضح
- أنا أعمل `push` على GitHub
- إنت تعمل `git pull` على جهازك وتشوف التغييرات

## ما تم اختباره

- ✅ عمل `clone` للـ repository
- ✅ إنشاء ملف README محلياً
- ✅ ضبط الـ Personal Access Token (PAT) بصلاحية `Contents: Read and write`
- ✅ عمل `push` للتعديلات على GitHub
- ✅ التأكد من أن الـ API بيقبل الكتابة بالـ token

## الخطوات الجاية

 دلوقتي الـ workflow جاهز، ممكن نبدأ نشتغل على ميزات حقيقية:
1. إنت تقولي الميزة أو التعديل اللي محتاجه
2. أنا أعمله وأعمل `commit` منفصل برسالة واضحة
3. أنا أعمل `push` على GitHub
4. إنت تعمل `git pull` وتشوفه عندك

## ملاحظات تقنية

- الـ token محفوظ في الـ remote URL محلياً (مش هيتسرب لحد تاني)
- كل ميزة هتكون في commit منفصل عشان تتابع بسهولة
- ممكن نشتغل على branch منفصل لو حابب تبقى الـ `main` نظيفة
